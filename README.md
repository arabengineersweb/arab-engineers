# Arab Engineers — Starter Project

This is a ready-to-deploy React + Vite + TailwindCSS project (JSON-driven content, AOS animations).
It is configured to be deployed to Vercel (Free plan).

## How to use

1. Unzip and open the folder.
2. Install dependencies:
   ```bash
   npm install
   ```
3. Run locally:
   ```bash
   npm run dev
   ```
4. Build for production:
   ```bash
   npm run build
   ```
5. Deploy to Vercel by importing the repo or uploading the folder.

## Notes
- Edit `src/content/content.json` to change English/Arabic content.
- Edit `src/content/styles.json` to change primary color, fonts, sizes.
- The language toggle is in the header (EN / العربية).
- Replace the `formspree` action with your own form endpoint or provider.
